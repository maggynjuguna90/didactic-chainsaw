# didactic-chainsaw
This project involves loading the wine data set from Schikit learn and performing PCA and TSNE on the dataset and comparing the output.PCA is good for quick interpretation  while TSNE is great for visualization.Perplexity of 30 worked best for this dataset and provided clear cluster separation.
